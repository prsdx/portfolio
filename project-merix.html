Merix

B2B SaaS platform that matches resumes to job descriptions using AI. Built for campus placement cells drowning in applications.

RoleSolo — design to deploy
Timeline2025 → ongoing
Statusv2 in progress
LinksGitHub · Live

The problem

Placement cells at colleges like mine get thousands of resumes per drive. Shortlisting is manual, slow, and inconsistent — the same student gets ranked differently depending on who reads the PDF that day.

What I built

A pipeline that ingests resumes and a job description, then returns ranked candidates with explanations, not just scores — a placement officer can see why each match ranked where it did.

PythonFastAPIOpenAI APINext.jsPostgreSQL

How it works

resume.pdf / jd.txt   → parser (PyMuPDF) → structured profile JSON   → embedding + scoring service (OpenAI + ranker)   → PostgreSQL (drives, candidates, explanations)   → FastAPI → Next.js dashboard for placement officers   → ranked list, each row with a written reason

The design constraint that shaped everything: placement officers won't trust a black box. Every score ships with a plain-language explanation generated from the matching evidence, so the tool assists a human decision instead of replacing it.

The hard parts

  • Resumes are chaos. Two-column PDFs, scanned images, 12-page CVs. The parser handles the 90% case gracefully and flags the rest for manual review instead of silently dropping candidates.
  • Embeddings alone rank badly. Pure similarity puts "Python" in the description above actual project evidence. The final score blends semantic match with structured signals — skills, recency, depth.
  • Cost per drive. Early prototypes re-embedded every resume per job. Caching profiles at ingest and embedding only the JD per drive cut API spend by roughly an order of magnitude.

Where it stands

Used in trial runs with sample drive data; v2 is a rebuild of the matching pipeline with better explanation quality and a cleaner officer workflow. The honest numbers go here once the next campus pilot finishes — this page gets updated with real results, not projections.
